# Mellow

Mellow 是一个 Chrome 插件，只调暗深色网页上刺眼的白字，背景、图片和图标保持原样。它是为散光、近视等看白字容易有光晕的眼睛做的。

深色网页上的纯白字和黑背景对比太强（GitHub 的正文对比度约 17:1），容易刺眼、看久了累。直接调暗屏幕，整个画面又会发暗，看着更费劲。Mellow 只压低最亮的那部分字，其他都不动。

## 效果

- **越亮的字降得越多**：纯白字降得最多，浅灰字降一点，本来就是灰色的字基本不动。主次文字的层次保持不变。
- **跟着背景走**：背景越黑，白字压得越低。字没超过"舒适上限"就不动。
- **只对深色页面生效**：自动识别深色页面和浅色页面，浅色页面保持原样。
- **彩色文字少调**：链接、代码高亮这些彩色的字调得少，颜色区分保留。
- **按钮上的字不动**：蓝色、绿色按钮，或者突然弹出的提示条，上面的白字保持原样，不会变得看不清。
- **不闪**：网页还没画出来就已经生效，不会先闪一下亮字。开关时有短暂的渐变。

不同背景下白字调整后的亮度（OKLCH 亮度 × 100）：

| 背景 | 亮度 93 的字（如 X 正文） | 亮度 97 的字（如 GitHub 正文） |
|---|---|---|
| 纯黑 | 77 | 77 |
| GitHub 深色 | 77 | 78 |
| 深蓝灰 | 78 | 80 |

## 使用

点工具栏上的 Mellow 图标打开弹窗：

- **总开关**：右上角，对所有网站开启或关闭。
- **此网站**：选择"自动"（深色页面才生效）、"始终开启"或"关闭"。
- **白字亮度**：右边的数字是当前网站正文的实际亮度。拖动只影响当前网站，其他网站不变。
- **柔化起点**：亮度超过这个值的字才会被调整。越高，越只影响最白的字。
- **彩色文字**：彩色文字调整的程度。
- **恢复默认**：把当前网站恢复为自动调整。
- **语言**：自动（跟随浏览器）、中文或英文。

快捷键 <kbd>⌥</kbd><kbd>⇧</kbd><kbd>M</kbd>（Windows 为 <kbd>Alt</kbd><kbd>Shift</kbd><kbd>M</kbd>）：在当前网站开启或关闭。

## 安装

需要 [Node.js](https://nodejs.org) 和 [pnpm](https://pnpm.io)。

```bash
pnpm install
```

```bash
pnpm build
```

然后在 Chrome 打开 `chrome://extensions`，打开右上角的"开发者模式"，点"加载已解压的扩展程序"，选择 `.output/chrome-mv3` 文件夹。

更新代码后重新 `pnpm build`，再在扩展页点 Mellow 的刷新按钮。已经打开的网页需要刷新才会用上新版本。

需要较新版本的 Chrome，用到了 CSS 的相对颜色语法（`oklch(from currentColor …)`）。

## 原理

1. **调色**：插件往页面里加一条样式规则，让每个元素的文字颜色在 [OKLCH](https://oklch.com) 颜色空间里只改亮度，色相和饱和度不变。亮度超过"柔化起点"的部分用一条平滑的曲线压缩：`L' = K + d / (1 + B·d)`，其中 `d = L − K`。这条曲线在起点处和原值平滑衔接，单调不回头，越亮压得越多。颜色由浏览器自己的样式引擎逐个元素计算，插件不逐个修改网页元素。
2. **舒适上限**：根据背景亮度，按"字和背景的对比度，加上屏幕和眼睛的散射光"算出一个上限，超过上限的字才往下压。背景越黑，上限越低。
3. **识别深浅页面**：在可视区域取 5×5 个点，找到每个点实际显示的背景色，按位置加权投票（中间的点权重更高）。
4. **保留按钮上的字**：背景是彩色或浅色的元素会被标记，里面的字保持原色。新出现的元素在画到屏幕之前就完成判断。
5. **省资源**：
   - 样式只在数值变化时才重写。
   - 读取颜色时，等浏览器自己算完样式再读，不额外触发计算。
   - 开关时的渐变分 12 小步完成，每步变化小到看不出，重算次数减少约 78%。
   - 页面里嵌的框（比如广告）不做定时检查。

## 隐私

- 不联网，不收集任何数据。
- 设置只保存在本机浏览器里。
- 只申请两个权限：`storage`（保存设置）和 `activeTab`（弹窗读取当前标签页）。

## 开发

| 命令 | 作用 |
|---|---|
| `pnpm dev` | 开发模式，自动打开一个装好插件的 Chrome，改代码后自动重新加载 |
| `pnpm build` | 构建到 `.output/chrome-mv3` |
| `pnpm zip` | 打包成 zip，用于上架 Chrome 应用商店 |
| `pnpm test` | 运行测试 |
| `pnpm typecheck` | 类型检查 |

技术栈：TypeScript、ESM、pnpm、[WXT](https://wxt.dev)（基于 Vite）、[Preact](https://preactjs.com)、Vitest。

## 目录结构

```
entrypoints/
  content.ts      注入每个网页：加样式、识别深浅、渐变、回应弹窗
  background.ts   快捷键
  popup/          弹窗入口
components/
  App.tsx         弹窗界面
  style.css       弹窗样式
lib/
  color.ts        sRGB 和 OKLCH 互转、解析浏览器给出的颜色
  curve.ts        调亮度的曲线、舒适上限、生成 CSS
  detect.ts       识别页面是深色还是浅色
  keep.ts         标记彩色或浅色背景上的元素
  text.ts         找出页面的主要正文颜色（弹窗显示实际亮度用）
  frame.ts        等浏览器算完样式后再读取
  fade.ts         分步渐变
  settings.ts     设置的默认值、读写和每个网站的设置
  i18n.ts         中英文文字
public/
  icon/           插件图标
  _locales/       插件名称和描述的中英文
assets/
  icon.svg        图标的原始设计文件
```
